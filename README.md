# 📊 Petrochemical Refinery VOC Emission Analysis Dashboard
A Power BI dashboard project for analyzing VOC emissions in a petrochemical refinery environment.

## 📖 Project Overview
This dashboard helps monitor:  
•	VOC emission trends   
•	Leak severity distribution   
•	High-risk leaking components   
•	Equipment-wise emission contribution   
•	Chronic leaking tags   
•	Plant-wise emission performance   
The project focuses on environmental monitoring, maintenance prioritization, and operational analytics using Power BI.  

## 📂 Dataset
### Table 1 — Plant_Data  
Contains operational LDAR monitoring data:  
•	Date   
•	Component Tag No.   
•	Equipment   
•	Components   
•	Plant   
•	Screening Value (ppm)   
•	VOC Emission (Kg/day)   
### Table 2 — Dates  
Custom calendar table used for time intelligence analysis:  
•	Date   
•	Year   
•	Quarter   
•	Month Name   

## 🎯 Key KPIs
•	Total VOC Emission   
•	Repair Efficiency   
•	Top Emitting Equipment  
•	Average Screening Value   
•	High Severity Leaks   
•	Total Components   

## 📈 Dashboard Features
•	VOC emission trend analysis   
•	Equipment-wise VOC ranking   
•	Leak severity monitoring   
•	Top leaking component identification    
•	Plant-wise VOC heatmap   
•	Chronic leak tracking   
•	Interactive slicers and filters   

## 🛠️ Tools & Technologies
•	Microsoft Power BI   
•	DAX   
•	Power Query   
•	Data Modeling   

## 📈 Key Insights
•	Monitored VOC emissions across 38,456 refinery components.    
•	Identified 128 high-severity leak cases.   
•	Recorded total VOC emissions of 89.66 kg/day.     
•	Identified Pump Seal as the highest VOC-emitting equipment category.    
•	Evaluated repair effectiveness with 92% VOC reduction after repairs.
